# AI Image Evaluation — Indian Ethnic Wear
### Josh Talks AI · Product Operations Hiring Challenge
 
A blind evaluation tool testing whether AI image generation models can produce product-ready photos of Indian ethnic wear for e-commerce platforms like Meesho, Flipkart, and Amazon India.
 
---
 
## What This Is
 
Three models — **Gemini Pro**, **Ideogram AI**, and **Adobe Firefly** — were given identical prompts across five Indian ethnic wear categories. 10 participants rated each image blindly (no model names shown) on two criteria:
 
- **Cultural Accuracy** — does this look authentically Indian?
- **Commercial Usability** — could this go live on a real product listing?
 
---
 
## The Tool Has Three Views
 
| Tab | What it does |
|-----|-------------|
| Rating Interface | Shows how participants evaluated images — blind, side by side |
| Results Dashboard | Score breakdowns, preference votes, key observations |
| Leaderboard | Model rankings with category winners |
 
---
 
## Prompts Tested
 
1. Red Banarasi silk saree — folded product shot
2. Royal blue lehenga choli — model shot
3. Cream kurta pyjama — men's model shot
4. Mustard anarkali suit — flat lay
5. Zari embroidery on green silk — close-up
